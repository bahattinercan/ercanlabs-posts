# ercanlabs-posts

Bu depo, **@ercanlabs** Instagram carousel görsellerinin herkese açık barındırma adresidir.

Instagram API, görselleri kendi sunucusundan indirir; bu yüzden görsel adreslerinin
public olması gerekir. Görseller 1080x1350 (4:5) PNG olarak üretilir.

Kaynak: `bahattinercan/orca-command-center` → `is/marketing/ig-gorseller/`
Üretici: `node is/marketing/ig-gorsel-uret.mjs`

| Klasör | Proje |
|---|---|
| `ig-gorseller/musteri-siparis-takip/` | İmalat atölyesi sipariş takibi |
| `ig-gorseller/local-ai-news/` | OpenWeight Radar |
| `ig-gorseller/style-lab/` | Tasarım stili kütüphanesi |
| `ig-gorseller/barber_shops/` | Berber randevu uygulaması |
